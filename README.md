**AI Image Classifier (iOS App)**

A SwiftUI-based iOS app that classifies images using Core ML and TensorFlow Lite models on-device in real-time. This project demonstrates integration of AI/ML workflows into a mobile application and optimization for smooth performance.
**Features**

Real-time image classification using MobileNetV2 and ResNet-50 models.
Pick images from the photo gallery or use the camera for live classification.
On-device inference for fast, offline predictions without needing internet connectivity.
SwiftUI interface ensuring a modern, responsive, and intuitive UX.
Optimized for low latency and high accuracy.
**Usage**

Launch the app.
Choose either:
Camera to capture live images, or
Gallery to select an existing image.
View real-time classification results.
**Learning Outcomes**

Implemented end-to-end machine learning workflows for iOS apps.
Gained experience in model optimization, on-device inference, and real-time prediction.
Developed clean and modular SwiftUI code, integrating AI seamlessly into mobile apps.
**Future Improvements**

Integrate custom datasets for domain-specific image recognition.
Implement Core ML quantization for faster and smaller model deployment.
